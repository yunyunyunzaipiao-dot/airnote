# AirNote / 空书：UI 风格与 Figma 交接（v0.3）

## 1. 你可以怎样向 Figma 说明偏好

不要只说“像 Apple”或“像 Figma”。更有效的表达方式是拆成：**气质、层级、形状、颜色、排版、动效、密度和禁区**。

推荐说法：

> 我喜欢现代、轻盈、圆角、克制的创作工具界面。参考 Figma 的工具组织效率和 Apple UI 的清晰层级、留白与细腻反馈，但不要复制任何品牌组件。画布内容是视觉主角，工具采用少量半透明或纯色浮动面板；使用柔和阴影、细边框、12–20px 圆角、清晰的图标与渐进披露。避免厚重侧栏、高饱和大色块、密集表单、装饰性渐变和“企业后台”感。

## 2. 可直接交给 Figma 的完整提示词

```text
请为 AirNote / 空书设计一个桌面端单工作区创意画布 UI。

产品定位：轻量的“空气输入 + 视觉画布”创意记录工具。默认用鼠标绘制；用户主动启用摄像头后，可以用捏合手势绘制。用户把笔迹确认生成为墨迹卡片，也可以新建基础文字卡片，并用连接线整理关系。

视觉气质：现代、轻盈、安静、圆角、简洁、精确。参考 Figma 的工具组织效率与 Apple UI 的层级、留白、材质和交互反馈，但不要直接复制品牌界面或图标。

布局：
1. 全屏画布是主角，占据绝大多数面积。
2. 顶部使用低高度工具栏，放工作区名称、保存状态、撤销/重做、清空、PNG/JPG/JSON 导出与 JSON 导入。
3. 左侧为紧凑的圆角浮动工具栏：选择、鼠标/手势模式、画笔、整笔橡皮擦、平移、矩形/自由选区、新建文字卡片。
4. 摄像头预览与校准采用按需展开，不要长期占据大面积。
5. 右下角放 25%–300% 缩放控件。
6. 右侧属性面板只在需要时出现，避免固定重侧栏。

组件：
- 墨迹卡片与文字卡片都使用 16px 左右圆角、细边框和轻柔阴影。
- 卡片选中后显示固定四角缩放柄和四边连接锚点，缩放柄不能随指针跳动。
- 文字卡片支持标题、正文、整卡粗体、斜体、下划线和文字颜色；不要设计复杂富文本工具栏。
- 整笔橡皮擦应明确表达“删除整条自由笔迹”，不能像像素橡皮擦。
- 破坏性操作使用克制的红色，并提供确认或撤销信息。

视觉参数建议：
- 8pt 间距体系；常用间距 8/12/16/24/32。
- 控件圆角 10–12px，浮动面板 16–20px，卡片 16px，胶囊按钮 999px。
- 浅色背景使用接近白色的中性色，不要纯白铺满；深色文字保持高对比。
- 主色仅用于选择、关键状态和主操作；成功、警告、危险颜色低饱和。
- 阴影柔和、扩散大、透明度低，同时用 1px 边框保证边界。
- 字体使用现代无衬线中文字体；标题 14–16px，正文 13–15px，辅助文字 11–12px。
- 动效 120–220ms，使用自然减速；尊重 reduced motion。

请输出：
1. Foundations：颜色、排版、间距、圆角、阴影、图标规范。
2. Components：按钮、工具按钮、浮动面板、卡片、缩放柄、连接锚点、Toast、Dialog、摄像头状态。
3. Variants：default / hover / pressed / selected / disabled / focus / error。
4. Desktop Frames：空画布、绘制中、分组建议、卡片整理、文字编辑、摄像头与校准、错误与确认状态。
5. 25%、100%、300% 缩放下的视觉检查。

不要设计：Gallery、多项目、登录、云同步、多人协作、图片卡片、局部橡皮擦、复杂富文本和首次启动遮罩式新手引导。
```

## 3. 建议的视觉令牌

以下是方向，不是必须逐字使用；Figma 可在保证对比度的前提下微调。

| 类别 | 建议 |
|---|---|
| Canvas background | `#F7F8FA` 或带极轻冷灰的近白色 |
| Surface | `#FFFFFF` / 92%–96% 不透明度 |
| Primary text | `#1D1D1F` |
| Secondary text | `#6E6E73` |
| Hairline | `rgba(29,29,31,0.10)` |
| Selection | `#0A84FF` |
| Selection soft | `rgba(10,132,255,0.12)` |
| Danger | `#FF453A`，只用于删除和错误 |
| Success | `#30A46C` |
| Control radius | `10–12px` |
| Panel radius | `16–20px` |
| Card radius | `16px` |
| Shadow | `0 8px 32px rgba(20,24,32,0.08)` + 细边框 |

## 4. 设计语言拆解

### “现代”

- 清晰网格、统一图标笔画、稳定组件状态。
- 信息层级靠尺寸、间距和明暗完成，不靠大量装饰。

### “轻盈”

- 面板尽量浮动且按需出现。
- 大面积留白、低饱和表面、细线和柔和阴影。
- 控件不长期覆盖内容；次要文字降低对比但仍满足可读性。

### “圆角”

- 不是所有元素都做成胶囊。
- 卡片、面板、弹窗用中大圆角；小工具按钮用 10–12px；只有短标签和缩放控件可用胶囊。

### “简洁”

- 每个常驻控件都必须服务 P0。
- 次级设置用 Popover 或 Inspector 渐进披露。
- 图标必须有 Tooltip 和可访问名称，不能只靠用户猜。

## 5. 必须设计清楚的交互细节

- 当前工具：强于 hover、弱于主操作，始终可辨识。
- 选择框：卡片边界、四角缩放柄和四边连接点各有明确视觉角色。
- 整笔橡皮擦：命中候选 Stroke 时整条高亮，避免产生“会擦掉局部”的误解。
- 文字编辑：编辑区和拖动区不能冲突；标题栏可拖动，正文区域用于输入。
- 摄像头：默认关闭；启用入口、运行状态、关闭入口和错误恢复清楚可见。
- 保存：使用“保存中 / 已保存 / 保存失败”，不要用永久成功 Toast 干扰。
- 缩放：百分比可点击回到 100%，极限为 25% 和 300%。
- 破坏性操作：卡片删除说明会删除笔迹和连接；清空说明可撤销。

## 7. 交付检查清单

- 所有常驻功能都能对应 P0 功能架构，没有 Gallery 入口。
- 设计了键盘 focus、hover、pressed、selected、disabled、error 状态。
- 卡片缩放柄固定在四角，没有自适应跳位。
- 文字卡片是基础整卡格式，不演变成富文本编辑器。
- 摄像头默认关闭，权限入口是显式按钮。
- 画布在 25%、100%、300% 下仍可操作。
- 浅色与深色内容具有足够对比度，文字与关键控件满足 WCAG AA 方向。
- 原型至少演示：绘制 → 生成墨迹卡片 → 新建文字卡片 → 连接 → 删除/撤销 → 导出。

## 8. 给设计师的一句判断标准

如果某个设计让用户更快地“画下来、整理成卡片、连起来”，它属于 AirNote；如果它主要让产品看起来像一个功能齐全的白板或项目管理工具，就应该删掉。
