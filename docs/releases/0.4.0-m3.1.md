# AirNote 0.4.0-m3.1

- 成立日期：2026-07-17
- 版本性质：M3 P0 可携带工作区
- 分支：`main`
- 功能集成提交：`80f3877`
- 同步记录提交：`629a431`
- 功能 ID：`SAVE-02`，并回归 `SAVE-01`、`UI-01` 与项目数据不变量

## 版本目标

在 M2 的“绘制 → 分组 → 卡片 → 连接 → 本地恢复”基础上，完成 PNG 与项目 JSON 的导出，以及全量校验后由用户确认的安全导入，使工作区内容可带走、可备份、可再次编辑。M3 完成 P0 数据可携带闭环，但不替代完整 P0 的发布验收。

## 已交付

- 顶部栏提供“导出图片”“导出项目”“导入项目”三个带文本和可访问名称的入口。
- PNG 按项目内容边界导出 Ink 笔迹、卡片、标题和连接，排除摄像头预览、HUD、选择框、分组建议、连接锚点和缩放柄。
- 项目 JSON 写入 `schemaVersion=1` 与 Workspace、Stroke、StrokeGroup、IdeaCard、Edge 和 Settings。
- 导入先在内存校验文件扩展名、MIME、JSON 结构、版本、全局唯一 ID 和对象引用；校验完成前不清空当前画布。
- 无效 JSON、过高版本和引用缺失分别显示明确中文提示；损坏引用会报告损坏对象数量。
- 校验成功后仍需用户确认；取消不修改内容，确认后替换工作区、清空运行时历史、切换到鼠标模式并立即保存。
- PNG 与卡片界面共用笔迹布局算法，不复制、删除、覆盖、替换或重排原始 Stroke 几何数据。

## 参数与产品决策

- 项目结构继续使用 `schemaVersion=1`，本版本没有不兼容的数据结构变化，因此不需要迁移。
- PNG 内容边界留白为 `48 CSS px`；空项目使用 `1280×720` 视口；单边最大输出为 `8192px`，超过时等比例缩小。
- 导入不合并当前画布，而是按 PRD 作为新会话替换；导入后的手势模式安全降级为鼠标，避免未授权自动启用摄像头或手势输入。
- 未新增依赖、后端、账号、云同步、上传、密钥或外部 API。

## 兼容性与数据

- M2 及更早的有效 `schemaVersion=1` 项目继续可读；Edge 可选锚点字段缺失时仍由运行时自动计算。
- 项目 JSON 不包含视频帧、关键点流、历史栈、访问令牌、API 密钥或 OCR 请求头。
- 导入取消、解析失败、版本过高或引用损坏均不会改变当前工作区。
- PNG 是视觉结果；项目 JSON 是可继续编辑的事实来源，Stroke 点序、坐标、颜色、粗细和样式保持不变。

## 已知限制与下一阶段

- M3 完成 `SAVE-02`，但完整 P0 MVP 仍需 M4 执行跨模块发布验收和稳定性收口。
- M4 需覆盖真实 Chrome/Edge 摄像头权限与设备错误、30 秒校准、连续 20 次捏合、丢手断笔、五分钟跨笔连接、100/10/15 压力恢复、高 DPI、性能和五名测试者无指导核心流程。
- 在 M4 达到完整 P0 发布标准前，不启动 P1。M5 只在 M4 验收发现需要独立稳定阶段时再决定，不是当前固定计划。

## 边界确认

没有摄像头录制或上传，没有关键点持久化，没有密钥、后端、账号或云同步；没有实现 OCR、Glow、Particle、张掌暂停、手势拖卡片、手势连线、手势模式 2、键盘自由文字或其他 P2 功能。所有破坏性操作仍需确认或可撤销，摄像头与模型失败时仍保留鼠标模式。
