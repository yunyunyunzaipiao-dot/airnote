# AirNote 0.2.0-m1.1

- 成立日期：2026-07-13
- 版本性质：M1 P0 基础绘图闭环
- 分支：`main`
- 主发布提交：`e3417d8`
- 功能 ID：`CAM-03`、`INPT-01`、`DRAW-01`、`DRAW-02`、`DRAW-03`、`EDIT-01`、`EDIT-02`，并回归 `CAM-01`、`CAM-02`、`GEST-01`、`UI-01`

## 版本目标

把 M0 临时诊断 Ink 升级为可校准、可鼠标降级、可保留画笔属性、可撤销恢复的正式 Stroke 基础闭环。本版本不包含卡片、连接和完整工作区保存，因此不宣称完成完整 P0。

## 已交付

- 四点 ROI、8%安全边距、三次捏合/松开采样、默认阈值回退、测试线和校准确认。
- 校准可明确跳过，摄像头面板提供直接使用默认参数入口。
- 鼠标与手势使用相同 Stroke 数据结构，输入切换时结束 activeStroke。
- 摄像头关闭、页面隐藏、窗口失焦、追踪中断和 Canvas 尺寸变化时安全断笔。
- 正式 Stroke、方向自适应轨迹处理、颜色和 `2/4/8px` 固定粗细。
- 50步撤销/重做、键盘快捷键、确认清空及一次完整撤销。
- 修复鼠标模式切回手势后捏合无法绘图的问题。

## 关键参数

- 默认捏合阈值：落笔 `0.35`、抬笔 `0.42`。
- writingROI：四点联合范围外扩 `8%`，最小宽高 `0.25`。
- 轨迹：方向自适应 EMA，最小点距 `2 CSS px`。
- 画笔：默认 `#172B3A`、`4px`，支持 `2/4/8px`。
- 历史：最多保留最新 `50` 步。
