# AirNote 0.3.0-m2.1

- 成立日期：2026-07-14
- 版本性质：M2 P0 想法卡片与连接工作区
- 分支：`main`
- 主发布提交：待生成
- 功能 ID：`GROUP-01`、`CARD-01`、`CARD-02`、`EDGE-01`、`SAVE-01`，并扩展 `EDIT-01`、`EDIT-02`

## 版本目标

把 M1 的正式 Stroke 基础闭环扩展为“笔画分组 → 用户确认生成卡片 → 鼠标整理和连接 → 本地自动恢复”的想法工作区。本版本不包含 `SAVE-02` 导入导出，因此不宣称完成完整 P0。

## 已交付

- 完成 Stroke 后加入唯一当前组，停笔1.2秒只显示建议，不自动生成卡片。
- 用户确认后按联合包围盒和安全留白创建 IdeaCard，卡片引用原 Stroke，不改写 `Stroke.points`。
- 卡片支持鼠标移动、双击改名、100字符限制、删除关联线确认和右下角尺寸调整。
- 卡片移动和缩放可撤销；`pointercancel` 不提交；卡片至少保持24px可见。
- 每张卡片提供上、右、下、左四个连接锚点，支持无向/有向连接、自连接和重复连接限制。
- 连接端点随卡片位置与尺寸实时更新；旧连接自动选择最近边。
- 完整工作区历史覆盖 Stroke、Group、Card、Edge、缩放和清空，至少保留50步。
- `schemaVersion=1` 项目快照以800ms防抖保存；恢复前执行ID和引用校验，损坏数据保留副本。

## 兼容性与数据

- 新增的 Edge 锚点字段为可选字段，旧 `schemaVersion=1` 项目无需迁移；缺失字段时运行时自动计算端点。
- 卡片缩放只修改 `IdeaCard.size` 和必要的位置边界，原始 Stroke 点序、坐标、颜色和粗细不变。
- 历史栈、摄像头帧、关键点流、密钥和令牌不写入项目快照。

## 边界确认

没有摄像头录制或上传，没有关键点持久化，没有密钥、后端、账号或云同步；没有实现OCR、Glow、Particle、张掌暂停、手势拖卡片、手势连线、手势模式2或键盘自由文字。
