# AirNote 0.1.0-m0.1

- 成立日期：2026-07-13
- 版本性质：M0 第一版低延迟技术尖峰
- 分支：`main`
- 功能 ID：`CAM-01`、`CAM-02`、`GEST-01`、`DRAW-02`、`UI-01`（部分验证）

## 版本目标

验证“视频帧 → 本地单手追踪 → 捏合状态机 → 轻量轨迹处理 → Canvas 2D Ink”的低延迟链路。本版本不宣称完成正式 M0/P0 数据闭环。

## 已交付

- 用户点击后才请求摄像头，支持关闭、卸载和页面隐藏时停止轨道与推理。
- 640×480、30 FPS 理想约束，镜像预览和实际分辨率反馈。
- 本地 MediaPipe 资源、单手 VIDEO 模式识别和最新帧优先处理。
- 捏合落笔、松开断笔、三帧丢手断笔和 250ms 中断保护。
- 方向自适应 EMA、2 CSS 像素抽样和 Canvas 2D 临时 Ink。
- 中文状态、错误提示和开发诊断 HUD。

## 关键参数

- 捏合落笔阈值：`0.35`。
- 松开抬笔阈值：`0.42`。
- 快速移动松开确认：最多 `3` 帧；移动阈值 `0.035`。
- 水平判定比例：`4.0`。
- EMA：水平前进轴 `0.62`、正交轴 `0.18`、其他方向 `0.5`。
- MediaPipe 检测/存在/追踪阈值：`0.6 / 0.5 / 0.35`。

## 验证

- `npm run typecheck`：通过。
- `npm test`：5 个测试文件、32 项测试全部通过。
- `npm run build`：通过，Vite 生产构建成功。
- 敏感文件扫描：未发现 `.env`、API 密钥、访问令牌、录像或私钥特征；`node_modules`、`dist`、日志、临时文件和测试录像均由 `.gitignore` 排除。

## 已知限制与下一阶段

- `CAM-03`、`INPT-01`、`DRAW-01`、`DRAW-03` 尚未完成。
- 临时 Canvas Ink 不创建正式 Stroke，不支持撤销、保存或导出。
- M1 必须继续完成 P0 基础绘图数据闭环，P1/P2 不进入实施。

## 边界确认

没有摄像头录制或上传，没有关键点持久化，没有密钥、后端、账号或云同步；未实现 OCR、Glow、Particle 或手势模式 2。
