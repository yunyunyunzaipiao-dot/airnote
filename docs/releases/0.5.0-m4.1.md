# AirNote 0.5.0-m4.1

- 成立日期：2026-07-17
- 版本性质：M4 完整 P0 里程碑
- 分支：`main`
- 功能 ID：M0–M3 已交付的全部 P0 功能

## 版本目标

确认摄像头/鼠标输入、正式 Stroke、笔画分组、想法卡片、连接、本地保存恢复、PNG 与项目 JSON 导入导出的完整 P0 闭环，形成进入 P1 前的稳定产品基线。

## 成立范围

- 摄像头由用户主动启用，失败时保留鼠标模式。
- 捏合落笔、松开和丢手断笔，原始 Stroke 持久化且不可由派生能力改写。
- 用户确认后生成卡片，并支持移动、改名、删除、调整尺寸和连接。
- 工作区自动保存、刷新恢复、完整撤销/重做及确认清空。
- PNG 导出与项目 JSON 的全量校验、确认导入和回读。

P1 实验视觉、张掌暂停和 OCR 均不属于本版本成立范围。

## 验证证据

- 负责人于 2026-07-17 明确确认“M4完成”。
- 当前进入 P1 后的回归结果：`npm run typecheck` 通过；12 个测试文件、70 项自动测试全部通过。
- M3 已记录导入导出、100 Stroke / 10 Card / 15 Edge JSON 往返及安全失败路径的自动验证。

## 兼容性与数据

- 项目继续使用 `schemaVersion=1`；M4 没有引入不兼容迁移。
- 项目数据不包含摄像头帧、关键点流、密钥、令牌或历史栈。
- Card、Edge 和 Stroke 引用不变量保持不变，鼠标模式仍是安全降级路径。

## 已知限制

- M4 的逐项人工验收明细未作为独立报告保存在仓库；版本成立依据为负责人确认与现有自动化记录。
- 真实设备、持续性能与浏览器权限差异仍需在相关改动后持续回归。
