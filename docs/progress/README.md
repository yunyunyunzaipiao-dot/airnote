# AirNote 每日进度

本目录用于记录每天实际发生的开发、测试和产品决策，文件名统一为 `YYYY-MM-DD.md`，日期采用 `Asia/Shanghai` 时区。

## 记录规则

- 修改了项目受版本控制文件的任务，在交付前必须更新当天文件。
- 同一天的多个任务按时间顺序追加，不覆盖已有内容。
- 纯咨询或只读检查默认不记录，用户明确要求时除外。
- 记录事实和验证结果，不把计划写成已经完成。
- 不记录摄像头帧、关键点流、密钥、令牌、环境变量值或个人敏感信息。
- 每次调参记录原值、新值、原因和验证结果。
- 未提交、未推送或未完成实机验收时必须明确标注。

## 条目模板

```markdown
## HH:mm｜任务名称

- 功能 ID / 优先级：例如 `GEST-01` / P0
- 完成内容：
- 关键文件：
- 参数与决策：
- 验证结果：
- 已知限制：
- 下一步：
- Git 状态：未提交 / 已提交；未推送 / 已推送
```

每日记录是开发事实来源，不等于正式版本发布说明。正式版本只有在负责人明确批准版本成立后，才按 [`../VERSIONING.md`](../VERSIONING.md) 汇总。
