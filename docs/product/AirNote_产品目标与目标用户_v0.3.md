# AirNote / 空书：产品目标与目标用户（v0.3）

> 用途：帮助产品、UI/UX 设计师与 Figma 明确“为谁设计、解决什么、什么不做”。  
> 当前阶段：单工作区 P0 基线。Gallery / 多项目已暂停。

## 1. 一句话定位

AirNote 是一款“空气输入 + 视觉画布”的轻量创意记录工具：用户可以用鼠标或本地摄像头手势留下笔迹，再把笔迹与简短文字整理成卡片和连接关系。

它不是完整白板、长篇文字编辑器或云端协作平台。

## 2. 目标用户

### 核心用户：视觉型思考者

- 学生、研究者、产品经理、设计师、内容创作者。
- 习惯边画边想，用关键词、箭头和空间关系组织思路。
- 希望快速开始，不愿先创建账号、项目库或复杂模板。
- 对手势输入感兴趣，但在摄像头不可用时仍需要可靠的鼠标方式。

### 典型使用情境

- 头脑风暴：先画零散笔迹，再整理为想法卡片并连接。
- 课堂或会议速记：笔迹记录重点，文字卡片补充可读说明。
- 个人构思：缩放和平移画布，查看局部与全局关系。
- 结果分享：导出透明 PNG、白底 JPG，或保存可继续编辑的项目 JSON。

## 3. 用户问题

1. 普通文本笔记很快，但难以保留“画出来、摆出来、连起来”的空间思考过程。
2. 完整白板工具功能重、入口多，短暂灵感的启动成本太高。
3. 手势演示常常只有新奇感，摄像头失败后就无法继续使用。
4. 笔迹和结构化内容容易互相替代，导致原始想法丢失或无法撤销。

## 4. 产品目标

### P0 产品目标

- 用户打开页面后直接进入一个可用工作区，不被引导遮罩阻塞。
- 用鼠标稳定绘制；用户主动启用摄像头后，可用捏合手势绘制。
- 把一组 Stroke 经用户确认生成墨迹卡片，不自动提交。
- 新建基础文字卡片，编辑标题与正文，并应用整卡基础格式。
- 移动、缩放、连接和删除卡片；所有破坏性操作有确认或可撤销。
- 画布可平移，缩放范围为 25%–300%，不同倍率下指针与内容一致。
- 用整笔橡皮擦删除自由 Stroke，不切割、不改写 Stroke.points。
- 自动保存在本地，并支持 schema v1 → v2 安全迁移。
- 导出透明 PNG、白底 JPG 和可继续编辑的项目 JSON。

### 成功标准

- 新用户无需口头指导完成：绘制 → 生成卡片 → 新建文字卡片 → 连接 → 刷新恢复。
- 摄像头拒绝、缺失、占用或追踪失败时，鼠标模式仍可完整工作。
- 删除卡片后，一次撤销可同时恢复 Card、Stroke 和 Edge。
- 在 25%、100%、300% 下绘制、拖动、缩放和连线不漂移。
- 导入失败时不替换当前工作区。

## 5. 产品原则

- **先捕捉，再整理**：绘制永远比结构化入口更直接。
- **原始事实优先**：视觉效果和 OCR 不改写 Stroke.points。
- **用户确认优先**：卡片生成、摄像头启用、破坏性操作均由用户明确触发。
- **鼠标是可靠基线**：手势是输入方式，不是使用产品的前置条件。
- **轻量而非齐全**：只保留完成创意记录闭环的工具。

## 6. 本轮不做

- Gallery、多项目、文件管理、缩略图和项目索引。
- 局部像素擦除、Stroke 切割。
- 分段富文本、Markdown、图片卡片。
- 账号、后端、云同步、多人协作、公开分享。
- 自动 OCR、完整摄像头画面上传、系统级输入法、XR。

## 7. 目标体验关键词

**轻、静、直接、可控、有空间感。**  
界面应让内容成为主角；工具像一组安静、可靠的浮动控件，不像专业软件的密集控制台。
